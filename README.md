# smb-automount

Автоподключение сетевой папки Windows (SMB) на macOS через корпоративный VPN.

Штатные «Объекты входа» здесь не работают: они срабатывают при входе в систему, когда VPN ещё не поднят, и подключение молча проваливается. Этот проект ставит фоновый агент, который ждёт появления сервера и монтирует папку сам — при входе в систему, после подключения VPN и после выхода из сна.

Настройка — двойным щелчком по приложению, терминал не нужен.

## Возможности

- Русские имена папок и пробелы в них.
- Подбор формы учётных данных: `ДОМЕН;логин`, просто `логин` или `логин@домен` — какая подойдёт серверу, та и запоминается.
- Выбор папки из списка, который запрашивается у сервера, вместо ввода имени руками.
- Пароль в связке ключей macOS, в файлах его нет.
- Том монтируется в `/Volumes/<имя папки>` и виден в Finder как обычный сетевой диск.
- Живой том проверяется чтением, а не пробой порта, и отцепляется только после трёх неудач подряд — иначе он мигал бы при каждой заминке VPN.
- Каждая попытка ограничена по времени, параллельные запуски блокируются.
- Понятный журнал: видно, ждём ли VPN, отказал ли сервер и по какой причине.

## Требования

macOS с системным bash 3.2 (то есть любая современная). Ничего доустанавливать не нужно: используются только `mount_smbfs`, `smbutil`, `security`, `launchctl` и `osascript`.

## Сборка

```bash
bash build/build.sh
```

Результат в `dist/`:

| Файл | Назначение |
|---|---|
| `Сетевая папка.app` | настройка и управление, двойной щелчок |
| `Журнал сетевой папки.app` | открывает журналы в TextEdit |
| `smb-automount-install.sh` | то же самое для терминала |

Сборщик подставляет `src/lib/common.sh` вместо маркера `@@COMMON@@`, встраивает рабочий скрипт вместо `@@WORKER@@`, проверяет синтаксис и совместимость с bash 3.2, затем собирает бандлы и архивы.

## Тесты

```bash
bash tests/run-tests.sh      # поведение рабочего скрипта на заглушках
bash tests/check-bash32.sh файл...   # совместимость с системным bash macOS
```

Настоящий сервер не нужен: `mount_smbfs`, `osascript`, `mount`, `nc` и `security` подменяются заглушками, проверяется журнал и факт монтирования. Покрыты: ожидание VPN, монтирование в `/Volumes`, устойчивость к заминкам сети, восстановление после разрыва сессии, откат в домашнюю папку и отказ сервера.

`check-bash32.sh` ловит `case` внутри `$( )` и обратный слэш внутри `${...}` — обе конструкции bash 5 переваривает, а системный bash 3.2 на macOS отвергает с кодом 258 ещё до первой строки вывода. Проверка встроена в сборку.

## Структура

```
src/
  lib/common.sh     общие функции: кодирование URL, формы логина, коды ошибок
  worker.sh         рабочий скрипт: монтирует и следит за состоянием
  app.sh            приложение с диалогами macOS
  cli-install.sh    установщик для терминала
  log-app.sh        приложение для просмотра журналов
build/build.sh      сборка dist/
tests/              тесты
docs/УСТАНОВКА.md   инструкция для пользователя
```

Рабочий скрипт устанавливается отдельным файлом и импортировать ничего не может, поэтому общие функции подставляются в него при сборке, а не подключаются во время работы.

## Что ставится на машину пользователя

| Путь | Что это |
|---|---|
| `~/bin/smb-automount.sh` | рабочий скрипт |
| `~/.config/smb-automount/<сервер-папка>.conf` | настройки, пароля нет |
| `~/Library/LaunchAgents/com.user.smb-automount.*.plist` | фоновый агент |
| `~/Library/Logs/smb-automount*.log` | журналы |
| `/Volumes/<имя папки>` | каталог для тома, создаётся один раз с правами администратора |

Удаление — пункт «Удалить» в приложении или `smb-automount-install.sh --uninstall`.
